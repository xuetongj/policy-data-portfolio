Philadelphia Census Data Tools

Retrieving and organizing American Community Survey data at city and census tract levels.

Project overview

Two Python scripts retrieve ACS 2024 five-year estimates (2020–2024) for Philadelphia city and its census tracts. Output records include estimates, margins of error and source information to support reproducibility.

Method

Using the Census API, the project retrieves geographic data, preserves data documentation, and saves structured CSV outputs for subsequent analysis. The original working files include city and tract datasets.

Interpretation note

ACS five-year data are period estimates, not a live count. Margins of error and special-value annotations matter when drawing conclusions, particularly for small geographies.
