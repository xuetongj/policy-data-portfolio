HUD Housing Counseling Search

A browser-based interface designed to help users locate HUD-approved housing counseling agencies and review contact information.

Project overview

The project combines an HTML/JavaScript user interface with a Python backend that retrieves agency data. The interface provides state-based search and a structured display of agency details.

Approach

The local implementation requests data through a Python API proxy, separating the user-facing interface from data retrieval. This demonstrates API integration, frontend presentation, and practical attention to public service accessibility.

Availability

Case study preview. The live search requires a Python backend and is not enabled in this static portfolio edition. This page does not represent a live HUD search service.

Tools
